Как собирать цены

Браузер не даёт странице самой ходить по чужим сайтам, поэтому цены попадают сюда тремя способами:

  1. Закладка. Перетащи эту ссылку на панель закладок: + В монитор. На странице книги в магазине нажми её: данные из карточки скопируются, потом нажми «Из закладки» и вставь.
  2. Импорт CSV. Колонки: title, author, publisher, isbn, shop, url, price, genre, mood.
  3. Вручную кнопкой «Добавить».

Чтобы обновить цену, снова нажми закладку на той же странице: в истории появится новая точка. Данные хранятся в этом браузере, делай «Экспорт» для копии.
