# Книжный монитор (GitHub)

Раз в сутки GitHub сам собирает цены с украинских магазинов и обновляет `docs/data.json`.
Страница `docs/index.html` публикуется через GitHub Pages и открывается с телефона по обычной ссылке.

## Установка (10 минут, команды не нужны)

1. **Создай репозиторий.** github.com → «+» → New repository. Имя `book-monitor`,
   **Public**, галочки «Add README» не ставь → Create repository.
2. **Загрузи файлы.** Распакуй архив. На странице нового репозитория нажми ссылку
   «uploading an existing file» и перетащи в окно *всё содержимое* папки (включая папки `app`, `config`,
   `docs`, `data` и `.github`). Внизу нажми Commit changes.
   - Если папка `.github` не загрузилась: Add file → Create new file, в поле имени введи
     `.github/workflows/crawl.yml` и вставь туда текст из файла `_workflow-copy.yml`.
3. **Разреши запись.** Settings → Actions → General → внизу «Workflow permissions» →
   **Read and write permissions** → Save.
4. **Запусти первый сбор.** Вкладка Actions → «Daily crawl» → Run workflow → Run workflow.
   Через несколько минут открой этот запуск: сверху будет таблица «Проверка доступа к магазинам».
   - «доступен» у магазина: всё хорошо.
   - «ПРОБЛЕМА» или коды 403/таймаут: магазин, скорее всего, блокирует зарубежные IP, и GitHub для него не подойдёт.
5. **Включи страницу.** Settings → Pages → Source: «Deploy from a branch» → Branch `main`, папка `/docs` → Save.
   Через минуту сверху появится адрес вида `https://ТВОЙ-ЛОГИН.github.io/book-monitor/`. Открой его с телефона.

## Что умеет страница

- **Жанр.** Определяется автоматически по категории книги в магазине (хлебные крошки). «Романтичне фентезі»
  хранится отдельно от «Фентезі»; в фильтре жанра есть пункт «★ Все фэнтези», который показывает оба.
  Жанр и настроение можно поправить вручную в карточке книги.
- **Каталог.** По умолчанию книги показываются плиткой с обложками (по 24, кнопка «Показать ещё»);
  можно переключиться на список. Клик по обложке открывает карточку: цены по магазинам, история, жанр.
  Есть год издания, фильтр «Год от / до» и сортировка «Сначала новые». Обложки и год подтягиваются
  по мере повторного обхода страниц магазинов (первые дни у части книг их не будет).
- **Цены.** Для каждой книги: самая низкая цена (и где), средняя, самая высокая (и где); внутри карточки
  таблица по всем магазинам и история цен.
- **Скидки.** Значок «−N%» ставится, если магазин указал старую цену или цена упала не менее чем на 5%
  от максимума за последние 60 дней. Есть фильтр «Только со скидкой» и сортировка «Больше скидка».
- **Умный поиск.** Находит автора и книгу по-русски и по-украински («Толкин» = «Толкін»), латиницей
  («Tolkien»), с опечатками («толкен», «сапковкси»), предлагает варианты под строкой поиска и подсказывает
  «Возможно, вы искали…». Переводные названия, которые пишутся совсем иначе («Властелин колец» и «Володар
  перснів»), берутся из `docs/aliases.json`: добавляй пары `["русское","украинское"]`.
- Поиск идёт по уже собранному каталогу. Когда сборщик обойдёт сайты, там будут все книги магазинов.

## Разделы страницы

- **Каталог** с фильтрами сбоку (на телефоне кнопка «Фильтры»), плиткой или списком.
- **Видавництва**: карточки издательств с мозаикой обложек; клик открывает каталог только этого издательства.
- **Знижки**: книги со скидкой, сначала самые выгодные.
- **Меню «⋯»**: добавить книгу, закладка, импорт, экспорт, помощь.
- **Карточка книги**: обложка, лучшая цена и кнопка «Купить», минимум/среднее/максимум, оценка,
  анотація (до 1500 символов, с кнопкой «Читати повністю»), список магазинов с историей цен, отзывы с кнопками перевода (Google Translate).
  Оценка и отзывы показываются, если в `data.json` у книги есть поля
  `"rating":{"value":4.3,"count":1340,"source":"Hardcover"}` и
  `"reviews":[{"text":"…","lang":"en","source":"Hardcover","url":"…"}]`.
  Пока источника нет, в карточке ссылки на поиск книги в Goodreads и Hardcover.

## Формат и характеристики

- **Формат.** Бумажные, электронные и аудиокниги разделены: по умолчанию показываются бумажные,
  фильтр «Формат» в колонке слева переключает.
- **Автор, ISBN, издательство.** Если магазин не отдаёт их в разметке, сборщик берёт их из блока
  характеристик на странице («Автор: …», таблица «Автор | …»). Отчёт Analyze shops показывает,
  у скольких книг каждого магазина это получилось.
- **Запуск с домашнего компьютера.** Workflow `analyze-local.yml` выполняется на твоём компьютере
  (self-hosted runner), то есть с украинского IP. Он нужен, чтобы проверить магазины,
  которые блокируют серверы GitHub (Yakaboo, Readeat, Книгарня Є).

## Что настроить дальше

- `config/shops.yaml`: впиши настоящие адреса Небо, Апріорі, РМ и поставь `enabled: true`.
  Для магазинов, где в sitemap много лишних страниц, добавь `product_url_regex` (шаблон адреса книги).
- За один запуск обрабатывается до 600 страниц на магазин, потом сборщик берёт следующие, пока не обойдёт весь
  каталог; затем каждый день обновляет самые давние. Пустые страницы (категории, авторы) запоминаются и
  перепроверяются раз в две недели.

## Важно знать

- Репозиторий публичный, значит, цены в `data.json` видны всем. Личные списки в него не клади.
- GitHub отключает плановые запуски, если в репозитории 60 дней нет активности. Если цены перестали
  обновляться, зайди в Actions и нажми Enable workflow или сделай любой коммит.
- Жанр и настроение, которые ты вписываешь на странице, сохраняются в браузере этого устройства,
  в репозиторий они не попадают.
- Уважай правила сайтов магазинов: сбор идёт медленно (пауза 1,5 с) и с учётом robots.txt.
